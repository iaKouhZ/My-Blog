# custom/ — 站点自建插件目录

本目录存放**只属于这个站点**的插件：按站点定制的抓取逻辑、内网地址、个人化展示等。
它与 `plugins/` 完全同权，同样能注册路由、挂钩子、开后台设置页。

## 为什么单独放一层

- 本目录被 `.gitignore` 忽略（只保留这个说明文件），所以这里的代码**不会被提交**，
  也不会在拉取上游更新时被覆盖或产生冲突。
- 想开源的插件请放 `plugins/`，并在 `plugins/README.md` §8 登记一行说明。

## 约定

1. 插件目录名即 slug：只允许小写字母、数字、连字符（`[a-z0-9-]{1,64}`）。
2. 主文件必须是 `{slug}.php`，头部注释必须含 `Plugin Name`，否则不会被识别：
   ```php
   <?php
   /**
    * Plugin Name: 我的插件
    * Description: 说明
    * Version: 1.0.0
    * Author: ...
    * Requires: 1.0
    */
   defined('APP_BOOT') or exit;
   ```
3. 与 `plugins/` 下的插件**同名时以 `plugins/` 为准**（随包插件优先，本地副本会被忽略）。
4. 插件自有静态资源（CSS/JS/图片）放在插件目录内，用 `plugin_url($slug, $path)` 引用。
5. 后台「插件」页可直接启用/禁用本目录下的插件；zip 上传更新已存在的插件时**就地覆盖**，
   不会把它搬到 `plugins/`。

## 编码要求

与 `plugins/README.md` 完全一致，重点重申三条最易踩的：

- PHP 7.4 语法兼容；禁止 Composer；禁止运行时 CDN（JS/CSS/字体）。
- 所有输出经 `e()`；输入一律走 `input_text/input_int/input_enum/...`，禁止直接读 `$_GET`/`$_POST`。
- 插件日志走 `plugin_log()`，不得写入明文密钥、验证码、授权码。

需要展示第三方图床/视频站封面时，走**可信图床白名单**：主机来自管理员在设置页的填写，
或由插件以**自身设置项的默认值**声明其功能直接依赖的主机（默认值须可见可改、清空不回退，
渲染逻辑中仍不得散落域名）。输出统一用 `ext_img()`，详见 `plugins/README.md` §7.1。
