# SMTP Mailer

预装且默认禁用。管理员在插件管理中启用，再配置 SMTP 主机、端口、加密方式、账号、授权码和发件人名称。
后台「发送测试邮件」可验证配置；授权码留空表示保留现有值，页面不回显。

插件通过 `register_verify_provider('email')` 声明渠道，通过 `send_verify_code` 接入发送。
验证码由内核生成；发送成功后调用 `VerificationService::recordSent()` 登记，有效期 10 分钟。
配额、最新码裁决、错误次数与原子消费由公共服务负责，插件只实现 SMTP 通道与邮件文案。
同渠道被其它插件接管时，本插件不发送、不写入；禁用后不再提供邮箱验证码能力。

错误次数默认 2，后台可配 1–5，内核再次钳制。发送结果经 `plugin_log()` 留痕，验证码和授权码不写日志。
邮件按站点 `admin_locale` 使用随插件发布的中英语言包；PHP SMTP 客户端无需 Composer。
